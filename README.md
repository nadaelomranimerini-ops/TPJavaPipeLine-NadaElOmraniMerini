\# TP Java Pipeline - Jenkins CI/CD



\## Réalisé par



Nada El Omrani Merini



\## Description



Ce projet est une application Java simple utilisée pour mettre en place un pipeline CI/CD avec Jenkins, GitHub, Docker, ngrok et Webhook GitHub.



\## Technologies utilisées



\- Java 17

\- Maven

\- Jenkins

\- Docker

\- GitHub

\- ngrok

\- Webhook GitHub



\## Étapes du pipeline Jenkins



1\. Checkout du code depuis GitHub

2\. Build du projet avec Maven

3\. Exécution des tests unitaires

4\. Packaging du projet

5\. Étape Docker Info



\## Jenkins



Le pipeline Jenkins est configuré avec un Multibranch Pipeline.
